# OpenAI Docs

Use the configured OpenAI-compatible API to support the author's workflow.

## Rules

- Keep project settings, selected Skills, source context, and generated assets distinct.
- Ask for missing story constraints before making irreversible creative decisions.
- Treat the author's notes as the final authority over style, canon, and revision direction.
- Return structured, editable drafts when the task creates worldbuilding, characters, chapters, or distilled rules.
- Never expose API keys or private local files in generated output.
